# Huawei MA56xx OLT Configuration Guide

This repository provides configuration examples and reference commands for Huawei MA56xx series OLTs. It includes detailed instructions for:

- GPON Configuration
- EPON Configuration
- Backup & Restore

## Folder Structure

```
├── gpon/
│   └── README.md
├── epon/
│   └── README.md
├── backup/
│   └── README.md
└── README.md
```

Each directory contains configurations and command references for the specific feature or protocol.
